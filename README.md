# SVG - Sentinel Vanguard Global

Global Supply Chain Risk Analysis Dashboard

## Overview

This repository contains the SVG Global Supply Chain Risk Dashboard - a professional web application that provides daily risk assessments across 8 geopolitical regions.

### Features

- Interactive risk map with Leaflet.js
- 30-day trend visualization with Chart.js
- Bilingual interface (German/English)
- Daily automated risk data updates
- 5-dimension scoring methodology per region

### Files

- `index.html` - Main dashboard application
- `risk-data.json` - Daily risk assessment data
- `supply-risk-updater/SKILL.md` - Automated update agent configuration

### Regions Monitored

1. Eastern Europe / Ukraine
2. Middle East
3. Taiwan Strait
4. Red Sea / Suez
5. Sahel Region
6. South China Sea
7. Central Asia
8. North Africa

### Scoring Methodology

Each region is scored 0-100 based on five dimensions (0-20 each):
- Conflict Intensity
- Trade Disruption
- Supply Chain Stress
- Political Instability
- Escalation Potential
